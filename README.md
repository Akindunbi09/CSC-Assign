# CSC 104 Assignment - Account Management

## Description
This project demonstrates Object-Oriented Programming (OOP) concepts in Python. It includes a base `Account` class and a `Savings_account` subclass.

## Key Features
* **Inheritance:** The Savings account inherits properties from the main Account class.
* **Method Overriding:** The withdrawal logic is customized for the Savings account.
* **Withdrawal Limit:** Implementation of a specific limit on how much can be taken out at once.
